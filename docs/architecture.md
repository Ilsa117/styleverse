# Architecture
Frontend (React + R3F) <-> Backend (FastAPI) <-> ML services (OpenCV / scikit-learn / TensorFlow)

Folders:
- `frontend/` UI, 3D rendering, AR
- `backend/` REST API, business logic
- `ml/` training scripts and notebooks
- `docs/` proposal, SRS, wireframes, paper
- `samples/` small test images / models
